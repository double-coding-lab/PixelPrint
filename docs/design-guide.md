# AI D2C 设计规范 · 设计师指南

> 本规范帮助设计师命名图层，让 AI 更准确地将设计稿转为代码。
> 规范越严格，生成质量越高，返工越少。

---

## 一、前缀速查

在图层名称**最前面**加前缀，多个前缀可以叠加，从左到右排列。


| 前缀         | 含义      | 效果                               | 示例                                     |
| ---------- | ------- | -------------------------------- | -------------------------------------- |
| `sub-`     | 独立模块    | AI 单独处理这一块，生成独立组件                | `sub-main`、`sub-qa`                    |
| `img-`     | 整块图片    | 整块导出为图片，内部不拆解                    | `img-banner`、`img-grid`                |
| `bg-`      | 背景图     | 设为父元素 background-image，不生成独立元素   | `bg-body`、`bg-card`                    |
| `bgc-`     | 父级背景与装饰 | 把填充/渐变/描边/圆角/阴影写到父元素 CSS，不生成独立元素 | `bgc-header`、`bgc-card`                |
| `btn-`     | 可点击区域   | 包裹可点击容器                          | `btn-submit`、`btn-img-banner`          |
| `block-`   | 独立布局块   | HTML/CSS 上与其他元素隔离，不可点击           | `block-price`、`block-action`           |
| `font-`    | 强制文字    | 只生成文字，不当图片处理                     | `font-title`                           |
| `scrollx-` | 横向滚动容器  | 子元素超出时可左右滑动；隐藏滚动条                | `scrollx-card-list`、`sub-scrollx-tabs` |
| `scrolly-` | 纵向滚动容器  | 子元素超出时可上下滑动；隐藏滚动条                | `scrolly-comments`                     |
| `fixed-`   | 视口固定定位 | 元素相对窗口定位（吸顶/吸底/悬浮按钮等），可与其他前缀叠加 | `fixed-btn-back-top`、`fixed-sub-nav` |
| `x-`       | 忽略      | 完全不生成代码                          | `x-标注`、`x-备注`                          |


**组合示例**：


| 图层名                 | 含义          | 生成结果         |
| ------------------- | ----------- | ------------ |
| `sub-img-qa`        | 独立模块 + 整块图片 | 独立组件，内容为一张图  |
| `btn-img-banner`    | 可点击 + 整块图片  | 可点击的 `<img>` |
| `sub-btn-entry`     | 独立模块 + 可点击  | 独立可点击组件      |
| `sub-scrollx-cards` | 独立模块 + 横向滚动 | 独立组件，内容横向可滑  |
| `fixed-btn-back-top` | 固定定位 + 可点击 | 相对窗口固定的可点击按钮 |
| `fixed-sub-nav` | 固定定位 + 独立模块 | 相对窗口固定的独立组件（如吸顶导航） |

## 二、前缀说明

### `sub-` — 独立模块

适合页面中相对独立的功能区块（主内容区、FAQ、底部等）。AI 会单独生成一个组件文件。

- 不影响内部渲染方式，内部前缀照常生效
- 整块要导出图片，用 `sub-img-xxx`
- 建议每个页面的一级区块都加 `sub-`

### `img-` — 整块图片

适合复杂插画、密集内容不需要还原文字的区域（红包网格、活动卡片等）。

- ⚠️ 加了 `img-` 后内部**所有子图层全部忽略**，整块导出一张图
- 内部文字不可交互、不可复制

### `bg-` — 背景图

适合复杂插画背景、有装饰纹理无法用 CSS 还原的背景。**纯渐变 / 纯色 / 仅描边圆角阴影的背景请用 `bgc-`**，避免位图缩放产生色带。

- ⚠️ `bg-` 图层高度**不代表父元素高度**，父元素高度由内容撑开
- 一个容器内只放**一个** `bg-` 图层
- 可搭配 `bgc-`：`bgc-` 写到父元素 CSS（颜色/描边/圆角），`bg-` 作为顶层图片覆盖
- ⚠️ `**bgc-` 应放在 `bg-` 的兄弟位置**（同一父容器），不要嵌在 `bg-` 子树里——否则 `bgc-` 的描边/圆角/阴影会被一起烤进位图，丢失或重复

### `bgc-` — 父级背景与盒级装饰

适合卡片底色、区块背景色、渐变背景、带描边/圆角/阴影的容器装饰。`bgc-` 不生成独立 HTML 元素，它的所有样式都写到**父元素**上。

**支持的属性**（从图层读取，自动转 CSS）：


| Figma 属性      | 对应 CSS                                                            |
| ------------- | ----------------------------------------------------------------- |
| 纯色填充          | `background-color`                                                |
| 线性渐变 / 径向渐变   | `background-image: linear-gradient(...)` / `radial-gradient(...)` |
| 描边 Outside    | `outline`（不挤占内部空间）                                                |
| 描边 Inside     | `border` + `box-sizing: border-box`（挤占内部空间）                       |
| 圆角            | `border-radius`                                                   |
| 投影 / 内阴影 / 模糊 | `box-shadow` / `box-shadow inset` / `filter: blur()`              |


**为什么优先用 `bgc-` 而不是切 `bg-` 图**：位图渲染的渐变在不同分辨率下会有色带（banding）；带 effect 的切图边缘会"沾染"画板底色；位图无法运行时切换主题。

### `btn-` — 可点击区域

适合按钮、入口、卡片跳转。不限定组件类型，AI 根据上下文决定用 `<button>` 还是 `<div>`。

### `block-` — 独立布局块

适合容器内需要独立样式命名空间的子区域。仅做布局隔离，**本身不可点击**。

- 与 `btn-` 区分：`btn-` = 可点击，`block-` = 仅隔离

### `scrollx-` / `scrolly-` — 滚动容器

当一块内容超出可视区，需要让用户左右滑或上下滑时使用。

- `scrollx-` = 横向滑动（如左右滚动的卡片列表、标签栏）
- `scrolly-` = 纵向滑动（如评论列表、长内容区）
- ⚠️ **必须给容器设固定宽（横滑）或固定高（竖滑）**，否则浏览器不会触发滚动
- ⚠️ 一个容器**只能选一个方向**，不要同时加 `scrollx-` 和 `scrolly-`
- ⚠️ 不能和 `img-` / `bg-` / `bgc-` / `btn-` / `x-` 一起用（语义冲突）
- 滚动条会自动隐藏（移动端体验默认）

### `fixed-` — 视口固定定位

适合吸顶导航、吸底 tab、悬浮回顶按钮、固定浮层入口等需要**相对窗口定位**（滚动页面时不跟着滚）的元素。

- **修饰前缀**：和其他前缀叠加使用，只改"定位方式"，不改"渲染方式"。例：
  - `fixed-btn-back-top` → 固定的回顶按钮
  - `fixed-sub-nav` → 固定吸顶的独立模块
  - `fixed-img-banner` → 固定的整张图
- **位置识别依赖 Figma constraints**：建议设计师为 `fixed-` 图层显式设置 constraints（top/bottom/left/right/center），AI 据此换算为 CSS 的 `top` / `bottom` / `left` / `right`。没设 constraints 会退化为绝对坐标定位，**滚动场景下可能错位**
- ⚠️ **不能**和 `bg-` / `bgc-` / `x-` 叠加：这三个不生成独立元素，没有节点可挂 `position: fixed`。要做"固定背景"请把 `fixed-` 加在父节点上（如 `fixed-sub-banner` 里面再放 `bg-banner`）
- ⚠️ **祖先元素不要做 transform / rotation / blur 效果**：CSS 规范下祖先有这些属性时，`fixed` 会退化为"相对祖先定位"，跟着祖先滚动而非相对窗口

### `x-` — 忽略

适合标注、说明文字、辅助参考线。优先级最高，内部有任何前缀也全部忽略。

## 三、布局建议

AI 生成代码默认使用 **flex 布局**。

**需要 Auto Layout 的情况**：容器内有多个子元素需要排列（普通容器、`btn-`、`block-`、`sub-` 内部有子元素时）。Auto Layout 的间距和方向会被精确还原为 `gap` / `padding` / `flex-direction`。

**不需要 Auto Layout 的情况**：

- 加了 `img-` 的图层——内部整块导出，AI 不解析子元素
- 加了 `bg-` / `bgc-` 的图层——本身不生成 HTML 元素
- 只有一个子元素的容器

❌ **避免**：需要 AI 解析排列的容器使用手动拖拽绝对定位（非 Auto Layout），AI 会尝试用 flex 还原，可能偏差。

**以下情况 AI 会自动使用绝对定位，不需要加前缀**：

- 角标、Badge（贴在元素角上）
- 浮层、弹窗
- 固定装饰元素

**常见错误**：


| ❌ 错误           | 问题                   | ✅ 正确            |
| -------------- | -------------------- | --------------- |
| 背景图层不加前缀       | AI 生成独立 `<img>` 而非背景 | 加 `bg-` 前缀      |
| 有文字的区域加 `img-` | 文字不可交互、不可复制          | 只对纯装饰区域加 `img-` |
| 整页无 `sub-` 分块  | AI 一次性解析整页，容易出错      | 按功能区用 `sub-` 分块 |
| 同一容器放多个 `bg-`  | AI 只取第一个，其余忽略        | 一个容器只放一个 `bg-`  |

## 四、图层结构案例

### 案例一：带背景图的按钮

```
btn-submit                   ← 可点击容器
├── bg-submit-bg            ← 按钮背景图
├── ¥1.9                    ← TEXT
└── 立即开通                  ← TEXT
```

效果：背景图铺满，文字叠加其上，整体可点击。

---

### 案例二：按钮内有多个子区域，整体只有一个点击事件

```
btn-buy-btn                  ← 整个按钮可点击
├── bg-buy-btn-bg           ← 按钮整体背景图
├── block-price             ← 左侧价格区（仅布局隔离）
│   ├── bg-price-bg         ← 价格区背景图
│   ├── ¥19.9               ← TEXT 原价
│   └── ¥1.9                ← TEXT 现价
└── block-action            ← 右侧操作区（仅布局隔离）
    └── 立即开通              ← TEXT
```

---

### 案例三：左右子区域各自独立可点击

```
block-buy-options           ← 整体容器，仅布局
├── btn-quick-buy            ← 左侧，独立可点击
│   ├── bg-quick-bg
│   ├── 快速购买
│   └── ¥1.9
└── btn-multi-buy            ← 右侧，独立可点击
    ├── bg-multi-bg
    ├── 多日购买
    └── ¥19.9
```

---

### 案例四：按钮右上角有角标

```
btn-open-btn                 ← 整个按钮可点击
├── bg-open-btn-bg          ← 按钮背景图
├── 立即开通                  ← TEXT
└── 59:59后失效               ← TEXT，Figma 中绝对定位，AI 自动处理
```

角标不需要加任何前缀，AI 根据 Figma 绝对定位自动生成 `position: absolute`。

---

### 案例五：完整活动页结构

```
双城卡页面（根 Frame）
├── bg-body                 ← 整页背景图
├── sub-main                ← 主内容区
│   ├── img-banner          ← 顶部插画（整块图片）
│   ├── 返现总额：88元         ← TEXT
│   └── btn-submit           ← 开通按钮
│       ├── bg-submit-bg    ← 按钮背景图
│       ├── block-price     ← 左侧价格区
│       │   ├── bg-price-bg
│       │   └── ¥1.9
│       └── 立即开通
├── sub-img-qa              ← Q&A 区（整块图片）
├── sub-benefits            ← 权益区
├── img-share               ← 分享区（整块图片）
└── img-footer              ← 底部（整块图片）
```
